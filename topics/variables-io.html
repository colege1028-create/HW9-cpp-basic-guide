變數與輸入輸出

讀懂資料從輸入、儲存到輸出的路徑。

不需要先備語法
問題語法範例逐步觀察易錯處動手預測

01 / 從問題出發

輸入兩個數字，程式怎麼記住它們？

想算出兩筆金額的總和，不能只讓程式「看到」數字；需要先把數字放進有名稱的位置，才能在下一行拿來計算。這就是變數的用途。

先記這一句先存值，再計算，最後輸出。

02 / 基本語法

先讀懂這個寫法。

把 a、b 想成兩個有名字的儲存位置。int 表示這裡存整數；= 把右邊算出的值存到左邊。程式依序往下執行，變數的值可能隨著每一行改變。

語法片段C++17
int count = 3;
double price = 12.5;
std::cin >> count;
std::cout << price << '\n';
int 與 double
int 用來存整數，double 用來存浮點數。先宣告型別與名稱，再使用變數；宣告時給初值比較容易追蹤資料。
cin >> 變數
把標準輸入讀進變數。連續寫成 std::cin >> a >> b;，就能依序讀入兩個值，空白或換行皆可分隔這裡的數字。
cout << 資料
把資料送到標準輸出。字串放在雙引號中；'\n' 表示換行。std:: 是標準函式庫名稱所屬的 namespace 前綴。
程式骨架與標點
#include <iostream> 提供輸入輸出宣告；main 是程式的起點，工作放在大括號內。一般敘述以分號結尾；return 0 表示正常結束。// 後面是給人閱讀的註解，不會被執行。

03 / 完整範例

讀入兩個整數，算出總和。

可將下方完整程式放進支援 C++17 的編譯環境執行。假設輸入成功，且兩個整數與相加結果皆在 int 可表示範圍內。

main.cppC++17
#include <iostream>

int main() {
    int a = 0;
    int b = 0;
    std::cin >> a >> b;

    // 先讀入兩個整數，再輸出它們的和。
    int sum = a + b;
    std::cout << "sum = " << sum << '\n';
    return 0;
}
範例輸入
3 5
預期輸出
sum = 8

04 / 逐步觀察

答案是怎麼出現的？

按「下一步」，只看這一步改變了什麼。範例輸入為 3 5。

程式追蹤1 / 5

先準備儲存位置

int a = 0; int b = 0;
a = 0　 b = 0

先宣告兩個整數變數，並給初值 0。

05 / 常見錯誤

卡住時，先檢查這幾點。

  • 把方向寫反

    輸入用 std::cin >> a;，輸出用 std::cout << a;。

  • 以為整數相除會保留小數

    5 / 2 的結果是整數 2；5.0 / 2 才會做浮點數除法，得到 2.5。先做整數除法，再存入 double，也不會補回小數。

  • 使用尚未賦值的變數

    不要讀取尚未初始化或賦值的區域整數變數。先給初值，再確認輸入成功後才使用輸入值。

06 / 換你預測

只改一個地方，結果會變嗎？

若把範例中的 int sum = a + b; 改成 int sum = a - b;，輸入仍是 3 5，會印出什麼？

想好再看答案 ＋
sum = -2

a 是 3，b 是 5，所以 3 − 5 = −2。只改了計算方式，輸入與輸出流程相同。
