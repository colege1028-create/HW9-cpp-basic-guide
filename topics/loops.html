迴圈

分開追蹤計數器 i 與累加器 sum，理解結束條件。

先讀：變數與條件判斷
問題語法範例逐步觀察易錯處動手預測

01 / 從問題出發

從 1 加到 5，每次到底改變了什麼？

要計算 1 + 2 + 3 + 4 + 5，可以一直寫加法；但範圍變大時就容易漏掉。迴圈能重複執行同一個動作：把「目前這個數字」加進總和，再換下一個數字。

先記這一句i 決定這次加誰；sum 保存目前累積的結果。

02 / 基本語法

先讀懂這個寫法。

for 的三個部分分別是起點、繼續條件、每次結束後的更新。執行順序是：初始化一次 → 檢查條件 → 執行本體 → 更新 → 再檢查。while 也在每次執行前檢查條件，但更新通常要自己寫在本體裡。

語法片段C++17
// for：初始化 → 檢查條件 → 執行本體 → 更新 → 再檢查。
for (int i = 1; i <= 5; i++) {
    std::cout << i << '\n';
}

// while：每次執行前先檢查條件，更新寫在本體中。
int j = 1;
while (j <= 5) {
    std::cout << j << '\n';
    j++;
}
先檢查，再執行
這裡的 for 和 while 都會先檢查條件。條件一開始就不成立時，本體一次也不會執行。
i++ 的用途
在這裡把 i 增加 1，讓迴圈往下一個數字前進。while 範例中的 j++ 也有相同作用。
累加器要先初始化
sum 從 0 開始，每次用 sum += i 加上目前的 i。這相當於 sum = sum + i。

03 / 完整範例

把 1 到 5，依序加進總和。

可將下方完整程式放進支援 C++17 的編譯環境執行。

main.cppC++17
#include <iostream>

int main() {
    int sum = 0;

    // 依序把 1、2、3、4、5 加入 sum。
    for (int i = 1; i <= 5; i++) {
        sum += i;
    }

    std::cout << "sum = " << sum << '\n';
    return 0;
}
範例輸入

不需要輸入

預期輸出
sum = 15

04 / 逐步觀察

答案是怎麼出現的？

按「下一步」，只看這一步改變了什麼。留意 i 和 sum 是兩個不同的變數。

程式追蹤1 / 7

開始前：準備累加器

int sum = 0; int i = 1;
i = 1　 sum = 0

總和從 0 開始；第一個要加的數是 1。

05 / 常見錯誤

卡住時，先檢查這幾點。

  • 少算或多算一次

    從 1 開始時，i < 5 只會跑到 4；i <= 5 才會包含 5。先確認起點、終點與是否包含端點。

  • 忘記更新條件相關變數

    while 中若忘記 j++，而 j <= 5 一直成立，迴圈就無法正常結束。

  • 把 sum = 0 放進本體

    每次重設 sum 就會丟掉先前累加的結果。累加器應在迴圈開始前初始化。

06 / 換你預測

只改一個地方，結果會變嗎？

若只把 i <= 5 改成 i < 5，最後的 sum 是多少？

想好再看答案 ＋
10

i 只能是 1、2、3、4；到了 5，5 < 5 不成立。所以總和是 1 + 2 + 3 + 4 = 10。
