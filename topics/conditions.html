01 / 從問題出發

同樣是分數，為什麼走進不同分支？

把分數分成三個等級：80 分以上是 A、60 到 79 分是 B、未滿 60 分是 C。關鍵是先檢查哪個門檻，以及找到符合條件後還會不會往下走。輸入假設為 0 到 100 的整數。

先記這一句由上往下，選中一個分支就結束這組判斷。

02 / 基本語法

先讀懂這個寫法。

if 的括號裡放條件；成立才執行大括號中的內容。else if 只有在前面的條件不成立時才會被檢查。else 接住前面都沒選中的情況。

語法片段C++17
if (score >= 80) {
    // 第一個條件成立時執行。
} else if (score >= 60) {
    // 前一個條件不成立，才檢查這裡。
} else {
    // 前面的條件都不成立時執行。
}
從上往下判斷
同一組 if / else if / else 只會選到一個分支。第一個成立的條件執行完後，會跳過後面的分支。
比較運算子
== 表示相等，!= 表示不相等，還有 >、<、>=、<=。比較結果可以作為 if 的條件。
組合條件
&& 表示兩個條件都要成立，|| 表示至少一個成立。例如 score >= 0 && score <= 100 可檢查範圍。

03 / 完整範例

輸入一個分數，選擇等級。

可將下方完整程式放進支援 C++17 的編譯環境執行。

main.cppC++17
#include <iostream>

int main() {
    int score = 0;
    std::cin >> score;

    // 先檢查較高門檻，避免高分先被較低門檻接走。
    if (score >= 80) {
        std::cout << "A\n";
    } else if (score >= 60) {
        std::cout << "B\n";
    } else {
        std::cout << "C\n";
    }
    return 0;
}
範例輸入
75
預期輸出
B

05 / 常見錯誤

卡住時，先檢查這幾點。

  • 把 = 當成 ==

    = 是指定值，== 才是比較是否相等。if (score = 60) 會改動 score，並不是檢查它是否等於 60。

  • 範圍順序放反

    若先寫 score >= 60，80 分也會先符合這個條件，後面的 score >= 80 就沒有機會被檢查。

  • 在 if 後面多寫分號

    不要寫 if (score >= 60);。這個分號會變成空敘述，使後面的區塊失去原本預期的條件控制。
